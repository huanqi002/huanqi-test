# Project Plan

## Objective

Deliver a student support and volunteer platform for the BIT 216 project. The repository currently contains the Support Session Manager module.

## Scope of This Module

- Select, register, or log out of a sample student or volunteer user.
- View accepted support requests and available sessions.
- Schedule or cancel a session.
- Mark a session complete and allow student feedback.
- Review session history.

## Delivery Workflow

1. Confirm requirements and agree on task owners as a team.
2. Implement each task on a short-lived Git branch.
3. Review and test changes through a pull request before merging to `main`.
4. Keep this plan and the testing notes current as scope changes.
